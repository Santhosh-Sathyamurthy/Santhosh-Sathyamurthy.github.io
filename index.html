About this site

Built by students, for students, kept to government standards

Accessible

WCAG 2.1 AA throughout

Keyboard navigation, visible focus states, resizable text, dark mode and screen-reader-friendly markup on every page. Read the accessibility statement.

Transparent

No club plays favourites

Clubs and councils are always ordered alphabetically or by date, never by size or seniority. It's a documented policy, not an accident. See the Council page.

Maintainable

Plain HTML, CSS and JS

No build step, no framework lock-in. Clubs and events live in two JSON files anyone on the Council can edit. See the handover README.
